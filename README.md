# Encrypted Messaging and File Transfer System

## Overview
A secure client-server messaging and file transfer system developed in C++/.NET.

The system allows users to communicate securely and transfer files using encryption mechanisms.

## Features
- Client-server architecture
- Secure messaging
- Secure file transfer
- User authentication
- RSA encryption
- AES encryption

## Technologies Used
- C#
- .NET
- Visual Studio
- Cryptography
- Client-Server Communication

## How to Run
1. Open the solution file in Visual Studio.
2. Build the project.
3. Run the server project.
4. Run the client project.
5. Connect the client to the server.

## Project Structure
- Messageu Client - Client-side application
- Messageu Server - Server-side application
